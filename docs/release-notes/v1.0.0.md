# Elytra Launcher v1.0.0

首个正式版本：把「下载 → 装配 → 启动 → 账号 → 联机 → 内容管理」放进一个跨平台启动器。

## 亮点

### 下载与安装

- 游戏版本多源下载：官方源 / 国内镜像三态（自动 · 仅官方 · 仅镜像），sha1 校验、并发下载与限速
- Fabric / Quilt / Forge / NeoForge / OptiFine 一键安装；纯原版 OptiFine 自动合并为自包含版本
- 缺失文件修复、JDK 扫描与 managed runtime 自动下载（Mojang → Azul 双源回退）
- Mod / 整合包 / 数据包 / 资源包 / 光影 / 地图在线搜索与安装（Modrinth · CurseForge），整合包支持 `.mrpack` / `.zip` 本地导入；CurseForge Key 可在设置中覆盖内置 Key
- Mod 依赖解析：安装前展示依赖链，逐项一键装入对应版本

### 内容管理

- 版本设置：Mod 更新检查与批量启停、存档、资源包、光影包、数据包、服务器列表、图标、游戏日志
- 启动脚本（`.bat` / `.sh`）与整合包（MRPACK）导出
- 多游戏目录管理；目录变化自动刷新
- 自动任务：启动前 / 退出后备份存档（保留 N 份）、记录 Mod 清单、打包崩溃日志（含脱敏）

### 账号与外观

- 微软正版登录（OAuth PKCE，多账号）、离线模式、第三方皮肤站（Yggdrasil 兼容）
- 皮肤衣柜：3D 全身预览、官方皮肤 / 披风切换与上传、本地皮肤收藏（仅正版账号）
- 皮肤绘画器：64×64 展开图 + 3D 直绘双模式，撤销重做、图层与实时预览

### 联机与工具箱

- EasyTier 虚拟局域网内嵌：房间码互连，无需公网服务器；跨网可配协调服务器
- 多线程下载器：URL 队列并发 + HTTP Range 分段，断点续传
- 服务器状态探测（Java SLP / 基岩版 RakNet）
- MOTD、物品 / 生物 NBT、指令生成器；烟花 / 药水 / 村民交易内联编辑器

### 界面

- 四套内置主题 + 自定义主题编辑器
- 中英文界面，运行时切换
- 全键盘导航与焦点管理、无边框自绘窗口

## 安装提示

1. Windows 安装版与便携版共用 `%APPDATA%\Elytra` 配置；游戏目录默认在启动器目录旁
2. 如果默认位置只读（MSI 装到 `Program Files`）或为空，请在「版本选择」页添加已有游戏目录
3. macOS 首次打开被 Gatekeeper 拦截时，右键应用 → 打开
4. Linux 使用 AppImage 前先 `chmod +x`；系统需要 WebKitGTK 与 GTK 运行库

## 已知问题

| 场景 | 说明 |
|---|---|
| Fabric/Quilt + OptiFine | 依赖 OptiFabric 桥接，兼容性有限；1.21+ 组合隐藏并报错。建议 Sodium + Iris，或原版/Forge + OptiFine |
| 跨网联机 | 依赖 EasyTier 协调服务器；MC 26.2 离线账号需走「局域网发现」，手动填 IP 可能报无效会话 |
| macOS | 未公证签名，首次打开需右键 → 打开 |
| Windows 卸载 | MSI 不清理 `%APPDATA%\Elytra`；NSIS 默认保留应用数据；都不会删除游戏目录 |
| CurseForge | 需要有效的 CurseForge API Key；内置 Key 失效时可在「设置 → 下载 → CurseForge Key」填入自己的 Key，未配置时该来源不可用，Modrinth 不受影响 |
| OptiFine | 官方无公开 API，部分版本 / 组合可能下载或安装失败 |

## 数据与卸载

- 配置目录：Windows `%APPDATA%\Elytra`；macOS `~/Library/Application Support/Elytra`；Linux `$XDG_DATA_HOME/Elytra`（缺省 `~/.local/share/Elytra`）
- 卸载不会删除游戏数据；手动指定的游戏目录也不在清理范围内
- 详细说明见 README 的「下载与安装」「运行时」与「已知限制」章节
