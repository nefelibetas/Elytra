## 不翻译

- 注册 id（`diamond_sword`、`minecraft:zombie`）
- ModLoader 名（Fabric / Quilt / Forge / NeoForge / OptiFine / OptiFabric）
- 文件路径、URL、HTTP 状态码、日志原文
- 第三方资源标题/简介原文（仅在用户选择翻译模式时展示中文译名）
- 用户输入（角色名、主题名、房间码）
