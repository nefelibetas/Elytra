# 截图规范

主 README 的「预览」区引用本目录的 6 张图，**文件名固定**——截图后直接覆盖同名文件即可生效，无需改动 README。

| 文件 | 内容 | 截取要点 |
|---|---|---|
| `01-launch.png` | 启动 | 已登录（或离线）状态，选中一个已安装版本，露出版本卡片与启动按钮；联机条在右栏 |
| `02-download.png` | 资源中心 | 任一非原版分类（Mod / 整合包 / 数据包 / 资源包 / 光影包 / 地图存档）有搜索结果；原版分类则展示版本列表 |
| `03-version-setup.png` | 版本设置 | Mod 管理 tab，列表有内容 |
| `04-skin-wardrobe.png` | 衣柜 | 仅正版账号；3D 全身预览 + 右侧皮肤 / 披风面板 |
| `05-skin-painter.png` | 皮肤绘画器 | 设置 → 工具；3D 直绘模式（或展开图模式），有实时 3D 预览 |
| `06-online.png` | 联机 | 启动页右栏；房间码与玩家列表 |

## 要求

- 尺寸 **1008 × 648**（与启动器窗口一致；高分屏可 2× 导出，保持同比例即可）
- PNG，单张尽量 < 300 KB（`oxipng` / `pngquant` 可压缩）
- 六张主题尽量统一（推荐默认「草方块绿」）
- **不要出现隐私信息**：真实账号名 / UUID、服务器地址、本地文件路径
